# Outline Index

The book's plot architecture: a small number of labelled threads, and a chapter-by-chapter outline grouped into arcs/acts.

**How to use this section.** Each thread file (see `Thread Template.md`) breaks one plot into numbered beats (e.g. **A1**, **A2**, **B1**, …). Each arc file (see `Arc Template.md`) lists its chapters with a short purpose and the beat codes that chapter advances. To find where a beat pays off, search the arc files for its code; to find what a chapter is for, read its beat list.

**Relationship to the rest of the codex.** `codex/plot/Macro Progression.md` stays the short phase-level summary. `codex/plot/Mystery Discovery Tracker.md` (if you have one) remains the authority on what has actually been revealed on the page — thread files describe intended sequence only.
