# Reviews

Per-chapter review reports land here — one file per report, named `<Chapter Name> - <reviewer> - <YYYY-MM-DD>.md` (e.g. `Chapter 4 - Title - pacing-review-2026-08-14.md`). This folder is separate from each chapter's own `drafts/` folder, which holds prior prose versions and the chapter's `Changelog.md`.

This file exists only so the folder is present in a fresh checkout; delete it once real reviews start landing here.
